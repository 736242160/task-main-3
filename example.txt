# ===== 事件流：播出流 + 中断流（按时间先后合并，跨流状态延续）=====
[events]
播出 CH1 开始 1      # 正常开播
中断 CH1 故障        # 在播节目被中断 -> 悬停 + 垫片 + 级联顺延

播出 CH1 结束 1      # 正常结束
播出 CH1 开始 2      # 队列节目正常播出
播出 CH1 结束 2
播出 CH1 开始 3      # 正常
播出 CH1 结束 3
播出 CH1 开始 3      # 同一顺序号重复播出 -> E_DUP
播出 CH2 开始 9      # 引用不存在节目单条目 -> E_REF
播出 CH2 开始 2      # 顺序不符（期望#1）-> E_ORDER
播出 CH2 结束 2
播出 CH2 结束 2      # 无在播却结束 -> E_STATE
