# 塔吊定义: CRANE 名称 x y 大臂长(m) 初始回转角(°) 初始幅度(m)
CRANE T1 0 0 50 0 40
CRANE T2 60 0 50 180 40
CRANE T3 0 80 40 90 30

# 正常回转
OP 1 回转 T1 45
# 变幅超行程（55 > 大臂长 50）
OP 2 变幅 T2 55
# 引用不存在的塔吊
OP 3 回转 T9 10
# T1 限位触发后再操作 → 拦截
LIMIT 4 T1 触发
OP 5 回转 T1 90
# 限位恢复后放行
LIMIT 6 T1 恢复
OP 7 变幅 T1 45
# T2 变幅到 45 后转到 135°，与 T1 大臂相交 → 干涉拦截
OP 7.5 变幅 T2 45
OP 8 回转 T2 135
# 同一时刻 T3 操作（与各方均不干涉）→ 放行
OP 8 回转 T3 0
# T2 换方向，避开 T1 → 放行
OP 9 回转 T2 90
# 同刻 LIMIT 先于 OP 生效 → 操作被限位拦截
LIMIT 10 T2 触发
OP 10 变幅 T2 30
# 同时刻两塔动作：T1 先接受并立即参与判定，T2 随后与其干涉 → 拦截
LIMIT 11 T2 恢复
OP 12 回转 T1 0
OP 12 回转 T2 180
